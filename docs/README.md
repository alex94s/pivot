## Description
**pivot** is an intelligent scheduling and planning tool that leverages OpenAI's ChatGPT to optimize personal and professional time management. It integrates with Apple Calendar, event feeds, and user priorities to provide interactive and dynamic scheduling recommendations, balancing structured planning with spontaneous opportunities.

## Requirements
The following requirements must be met prior to running the pivot modules:

1. **Python Environment**:
   - Ensure all dependent packages are installed (`requirements.txt`).
2. **Calendar Integration**:
   - MAC OS with Apple Calendar.
3. **OpenAI Account**:
   - A funded OpenAI account with set environment variable for API key.

### Environment Variables Setup
Running the following commands in the terminal **within the project environment** will create the necessary environment variables:

  ```bash
  export OPENAI_API_KEY='your_api_key'
  export CALENDAR_API_KEY='your_calendar_api_key'
  export EVENT_FEED_API_KEY='your_event_feed_api_key'
  ```

## Modules

### Schedule
- **File**: `schedule.py`
- **Purpose**: This script adds events to the macOS Calendar app using AppleScript, including dynamic suggestions.
- **Features**:
   - Uses AppleScript to interact with macOS Calendar.
   - Generates event recommendations based on user input and availability.
   - Works with existing calendar data to prevent conflicts.

### Nudge
- **File**: `nudge.py`
- **Purpose**: This module generates unique, practical nudges to help users break their routine in meaningful ways. It uses the OpenAI GPT-4 model to provide insightful suggestions based on a variety of prompts.
- **Features**:
   - Uses OpenAI to generate creative nudges for users.
   - Dynamically selects nudges based on various themes and personal interests.
   - Ensures variety and non-repetitive prompts.

### Pulse
- **File**: `pulse.py`
- **Purpose**: This module scrapes and aggregates events from various sources, providing real-time event data for different cities.
- **Features**:
   - Collects event data from platforms like Ticketmaster, TimeOut, Eventbrite, Meetup, and Atlas Obscura.
   - Uses a standardized structure for different event sources with a flexible, extendable design.
   - Dynamically selects a random event source for diversified event recommendations.
   - Extracts relevant event details, including title, description, time, location, and links. 

## Testing
A suite of unit tests are located in the `tests` folder. Each script targets a specific module, ensuring code reliability and functionality:

- **`test_schedule.py`**: Unit tests for the Schedule module.
- **`test_nudge.py`**: Unit tests for the Nudge module.
- **`test_pulse.py`**: Unit tests for the Pulse module.

The following command may be used to run all tests:

```bash
python -m unittest discover tests
```
